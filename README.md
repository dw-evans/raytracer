# Writing a Path Traced Rendering Engine from Scratch

I got a little curious about the maths behind rendering. Curious enough that I decided to write my own rendering engine from scratch in Python and OpenGL.

I last worked on this project around a year ago, and picked it up in September 2025 again to see what it is capable of - turns out it works quite well given enough render time.
